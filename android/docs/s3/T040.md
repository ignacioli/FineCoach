# T040 提示行、左滑与撤销

提示行是 feature 内组件，今日、完整列表、学员详情共用。几何按 S3-D13 / S3-D15：分割线下 `space.3`，主文字 `body`，`space.1`，副文字 `caption`，再 `space.3`。整行是一个跳转按钮，没有 `›`，也没有「…」。

文案拼法跟 iOS `InsightRowContent`。今日和完整列表的主文字带学员名，学员详情不带。停滞行三种上下文不同。撤销文案「<学员名> · 已暂不提醒 14 天」，学员详情不带学员名，复用 `FcUndoRow`，4 秒后从这一次快照里拿掉。

左滑可以一滑到底，不弹确认。露出的胶囊在只做轻推时对无障碍隐藏；行打开后同一胶囊是可见的「暂不提醒」。行的 `contentDescription` 使用分组、学员（详情除外）、主文字、副文字；内部 nudge phase 不再挂到 TalkBack。TalkBack 自定义操作也是「暂不提醒」。首次轻推只在今日、每台设备一次；`ANIMATOR_DURATION_SCALE` 为 0 时不播，也不把已播放写成 true。

和 iOS 的差别：行高按画板 70 的间距堆叠，不照 iOS 约 53。没有 `bell.slash` 资源，胶囊用现有 `ic_ms_notifications`。撤销行仍是共享组件自己的最小高度，没有为了贴 70 去改它。

`InsightEntryLayoutTests` 9/0/0/0；另有 `InsightTestPrivacyRuleTests` 1/0/0/0。日志 `.handoff/logs/agent-test-android-s3-p5-20261121-182831.log`。覆盖真实完整列表入口与目的页、三种直达、无未来课程时预填、TalkBack 分组朗读与胶囊隐藏、后台读取轻推标记、重载及列表往返保留原始 4 秒撤销截止时间。

撤销 pending 与截止时间由 `InsightBoardState` 持有；重新加载恢复原位置，页面重建只等待剩余时间，过期保留已写入的暂不提醒。撤销写入成功后再移除 pending。
