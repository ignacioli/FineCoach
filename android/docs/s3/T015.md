## 输入投影与 iOS 对齐
- `s3.gains`：当前/历史均通过给定 session ID、student ID、started/completed instant、focus、exercise ID/source ID/mode、set ID/order/state/input 构造。共享 `context` 显式给学生/动作虚构名、sourceKind、order、notes、revision、statistics 与 latestReport=null；不生成随机 ID。set 时间沿用该 session 的 completed instant；TrainingSetInput 可选字段采用两端 initializer 的 nil 默认，sectionID 采用 nil 默认。`SessionGains` 为直接入口。
- `s3.insights`：StudentDraft(name,sex) + given created instant；archived 显式应用；CoursePackage(id,student,totalCredits,endDate,now)，其余采用 initializer 默认；余额作为账本已计算的纯领域输入。Appointment(id,student,date,time,status,now)，其余采用 initializer 默认。真实账本 application 路径另由 RoomMigrationV4Tests 证明。
- `s3.e1rm`：直接调用 EstimatedOneRepMax.value；期望写死字符串。Foundation Decimal 的除法先放大 10^38，再按 8×UInt16 mantissa 截断，加法对齐 exponent；不做显示取整。`50×(1+2/30)` 在 iOS 的实际运算顺序是 `50 + 50*2/30`，期望 `53.33333333333333333333333333333333`。
- `s3.compare` / `s3.records` / `s3.trend`：直接调用 Comparison 同名入口；PR 不使用 e1rm；LoadDirection 显式给定。
- `s3.body-display` / `s3.body-upsert`：直接调用 BuiltInUnitConversion 与 BodyMeasurementDayIndex；body 值不进入诊断，仅失败路径 / vector ID 可打印。
- 固定 now、IANA `America/Los_Angeles`；包含 DST 周、周日 23:59 / 周一 0:00。UUID 投影结果统一 lower-case（仅测试比较，不改变产品格式）；iOS snooze key 的 Student UUID 采用其原生 upper-case。
