# T031 训练历史：选择两节课并比较

可见「选择」进入选择模式，每行有「选择这节课」/「已选」。选满两节后调用已有的 `Comparison.compareSessions`。训练重点集合不同，或不是同一学员时，显示「训练重点不同，无法对比，已分别展示。」集合相同则并排总组数、总次数、训练容量，以及「动作相同」或「仅此次 · …」。比较不写 Room。

与 iOS 的差异：iOS 比较可以在趋势页的顶层分段里。S3-D03 把入口放在训练历史，本页没有那三个顶层分段。文案沿用 iOS。

测试：`HistoryCompareEntryLayoutTests` 1/0。日志 `.handoff/logs/agent-test-android-s3-p4-20261120-020153.log`。不要在进页面之前于夹具线程预拉列表，否则页面里的第二次 `list()` 会停在 `busy=true`。
