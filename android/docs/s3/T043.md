# T043 直达

课包三种提示进入该学员的课包页。续课包仍走 S1「先确认再结束旧课包」，这里不结束旧课包。很久没来进入新建安排，并在页面加载前写入这个学员。停滞进入该动作的训练趋势，进入前选中这个动作。

`InsightRoutes` 组装具体路径；`S1Routes` 新增 3 个 route pattern：`INSIGHTS`、`INSIGHT_APPOINTMENT`、`INSIGHT_TREND`，并加入 `ALL`；`ScopeBoundaryTests` 的三项放行与实际 pattern 一致。条件消失后下一次 `load()` 不再包含这条。`InsightEntryLayoutTests.moreThanThreeShowsAllAndAResolvedConditionDisappearsOnNextLoad` 给其中一名学员加了未来安排，再加载后那一条不在今日区块里。`threeDestinationsAndStudentDetailOmitsTheName` 点了课包、很久没来、停滞三行，渲染并检查课包页、新建课程安排页（预填该学员）和训练趋势页（预选动作的页面内容），不再用生产路由常量作为期望。

和 iOS 的差别：新建安排的学员预填是在现有编辑页状态上赋值，没有新的编辑器参数。趋势页用已有的 `selectExercise`。
