# T032 身体数据列表与录入

同一学员、同一指标、同一本地自然日再录一次，走已有的 `recordMeasurement` upsert，仍是一条。删除先出确认对话框「删除这条记录？」；取消不删，确认后删除并重新 `load`，趋势按剩下的记录重算。内置单位切换只改显示，存储仍是录入时的单位和数值。自定义指标保存录入的数值和单位。断言消息不包含测量值。

自然日用 `BodyDataUseCases` 已有的 `ZoneId`（图上的 `graph.zone`）。iOS 也按本地日历日去重。没有发现需要负责人裁决的分支。
