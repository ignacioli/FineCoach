## 与 iOS DesignValueScanTests.swift 的差异表

| 边界 | Android | 当前 iOS | 理由 |
|---|---|---|---|
| 单位/尺寸 | 任意 dp/sp 扩展、Dp/TextUnit 构造、dimensionResource | 不查一般 frame 尺寸；查内置 `.font(.…)` | 本轮明确补漏要求 |
| 颜色 | 任意 Color 构造/静态入口、android.graphics.Color、colorResource | Color(red/hex)、UIColor 与系统色名单、foregroundStyle/Color 简写 | 平台 API 对应及本轮补漏 |
| 字体/theme | FontWeight 构造、FontFamily 静态成员、MaterialTheme 两类直接取值 | `.font(.…)` 内置字体入口 | 防页面绕过 DS |
| 零值 | 只豁免间距完整字面量 0/0.dp；其他设计值的零仍拒绝 | 非零 padding/spacing 拒绝，圆角零仍查 | 沿用零间距边界，修掉 float 被前缀误认的问题 |
| 圆角/裸排版 | *CornerShape 数字含 percent/裸整数；字号/行高/字距裸数字 | cornerRadius 裸数字；字体入口扫描 | Kotlin/Compose 的旁路形式 |
| alpha/opacity | 不扫描 | 不扫描 | 对照 iOS 后按指令保持一致 |
| 字符串/注释 | 整体屏蔽字符串、字符、行/块注释，保留行号 | 只跳过以 // 开头的行，不屏蔽整段字符串 | 避免文案或代码示例被误报为实际设计值；代价是字符串模板内插值代码未覆盖 |
| 根目录/计数 | 缺根/空扫描硬失败，输出实际文件数与分目录违规数 | 缺 App 根会 XCTSkip；不输出扫描文件计数 | Android gate 明确禁止空证据/skip |
