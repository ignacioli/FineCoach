## 与 spec 的差异

FR-002 写开始时间已过；iOS `Appointment.swift:108-109` 实际以结束时间 ≤ now 判逾期，按本轮指示使用 iOS 行为。不会自动更改状态。FR-005 限定本次及以后字段，Android API 不暴露 iOS 用例允许的 intervalDays 参数；保留 iOS boundaryTrainingFocus 仅作用 boundary 的行为。
