## 登记表方案

复用 Room store_metadata 单键 JSON（仅 UUID、时间戳、时区、精确模式），无 schema 变更。每项先 cancel 旧 OS 闹钟并删除旧登记，set 成功后才写入该条新登记；set 抛异常不留下新登记，下次非强制 reconcile 可重新注册。若进程在 set 成功后、写登记之前退出，同一 PendingIntent 的重设仍会收敛，不依赖强制对账补救。启动不阻塞 S1 catalog/recovery；恢复完成后 IO 协程只启动一次强制对账。Room flow 禁止初始发射；permissionRevision 初值与首次 ON_RESUME 不触发，后续变更/真正 stop→resume 经 conflated channel 合并；系统广播强制重排；Mutex 串行化读库和 OS 操作。通知接收重新读 Room，取消/删除/替换的旧广播不得泄露或发出过时内容。

VISIBILITY_PUBLIC：正文只有通用文案与 HH:mm，与 iOS 锁屏可见内容一致；extras 只有不透明 UUID。独立渠道 appointment-reminders，不改 S1 渠道。
