### 恢复入口与尚未解决的差异

- iOS 今日通过 `.task` 和 navigation path 变化重读（`TodayView.swift:228,239`）；学员列表通过 `.task`、path 变化及 query 变化重读（`StudentListView.swift:203,205,235`）。这些是生命周期/查询恢复，不是可见错误按钮。Android 保留既有 `today-retry`、`studentList.error-retry` 及两种启动 retry，避免唯一直接恢复路径消失；未改业务合同。
- 咖啡热气本来就是获批的代码描边，上一版“无图片所以不绘制”的理由错误。现按 components §4.9、README §14.2 与 iOS FCMotion / FCAmbientEmptyScene 补齐第四层 Canvas，使用 textDisabled token 和原220坐标、2.2圆头描边。减弱动态两缕0.45透明、静止；正常三缕按3.6秒周期/1.2秒相位绘制，呼吸与热气使用 easeInOut；暂停时立即睁眼，恢复后按累计时间继续。纯帧/路径断言已补，系统设置下实际事件与人工观感仍未确认。
- AD-01 缺口：杠铃和 list.bullet.rectangle 均无已接入符号；动作库保留既有 grid_view，模板传 null，移除会误导为筛选的 filter_list。正式图标待 S0 图标对照板审批后接入。
