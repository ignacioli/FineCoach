## 1. 安装

先按 [Android README](../../README.md) 配好 JDK21、SDK 与缓存，在 S1 集成 worktree（`.claude/worktrees/android-s1`，分支 `feat/android-s1-coach-core`）的 `android/` 目录执行；把 `<SERIAL>` 换成目标设备的实际 serial：

```sh
./gradlew --offline :app:s0InstallSeededDebug -Pandroid.device="<SERIAL>" -Ps1.seedScenario=multi
```

- 模拟器：启动专用虚构 AVD，只连接这一个设备。宿主已在 `FineCoach_QPR2_API36_1` / `emulator-5554` 装好并连跑两次；直接打开 FineCoach 即可走查。重新安装时，serial 用 `emulator-5554`。
- Pixel 8a：开启 USB 调试、连接电脑并授权，断开其他模拟器/设备；用手机的 serial 替换占位符，再执行同一命令。**只接受全新数据目录，或同版本、同场景的 seed 库。手机已有其他数据时，种子安装会被拒绝；工具不会清库或覆盖这些数据。** 不在手机执行卸载或清理（S1-D22），遇到拒绝交负责人自行决定。
- 默认打开 S1，不需要启动开关。成功预期为 `SEED version=1 rows=66 status=ok` 和 `s0InstallSeededDebug: status=ok …`。重复运行保留体验中修改过的数据，不恢复初始内容；rows是首次初始化计数，不是当前剩余记录数。
- 单训练/空列表的独立初始场景可在另一份全新专用虚构 AVD 上，把参数改成 `single` / `empty`（rows分别55/5）；不能在已有 multi 库上靠改参数切换或重置。

## 4. 亲手点一遍：操作 → 预期结果

### 今日与学员

- 切换今日/学员，分别打开两位学员的训练卡，再返回 → 各自回到原课，不串课、不另开课；结束一课后Today变为单训练入口。
- 搜索姓名、进入详情；新建同名虚构学员，先缺姓名/sex再补齐保存 → 必填提示可理解，同名可共存，保存后可再找到。
- 编辑可选资料并清空，再分别保存/取消/系统返回 → 保存才改变资料；取消不写入；键盘出现时保存按钮仍可达。
- 归档、取消归档确认、恢复学员7；对新建虚构学员尝试错名删除/正确姓名删除 → 取消或错名不删除，有进行中训练时拒绝删除；正确删除范围以D05为准。

### 课包

- 未到期且余额非零的旧包上新建，先取消替换再确认替换 → 取消保留原包；确认后旧包ended、新包active，账本历史保留。
- 查看到期、耗尽、ended及无包学员；新建反向起止日期的虚构包 → 不把到期/耗尽当新生命周期，不额外禁止反向日期。
- 手工扣减/返还填数量和原因，分别保存/取消；查看流水，再明确结束课包 → 只有保存或确认结束才写入，余额来源可查，不能扣成负数。

### 动作与模板

- 搜索动作，快速“仅本节使用”，另一次明确“加入动作库”后点选 → 前者不进入全局库，后者是显式创建；新名称不会回写历史快照。
- 在动作选项改显示名、收藏、辅助/单侧偏好，隐藏再恢复；编辑输入后点取消 → 已保存偏好保留，取消的草稿不写入，取消按钮可见可点。
- 打开指定模板，改名称/重点，分别保存/取消；计划组试kg/lb、单侧/双侧左右值和有氧四字段 → 保存后再打开仍在，取消保留原值。
- 新建/重命名/重排分段与动作，移动动作到分段或未分段；删除非空分段先取消再确认 → 取消不改，确认后动作和组保留并移到未分段；空分段可直接删。
- 从训练页点“应用模板”，先取消再明确应用 → 取消不改当前课（列表读取时也可取消）；应用后为独立pending组，不能直接算已完成；菜单中的取消入口都应可点。

### 训练、休息与恢复

- 四mode输入，检查0重量、正次数/时长、有氧距离，以及左右侧字段；确认本组 → 合法值才completed并计统计，输入或预填本身不算完成。
- 组操作中编辑、复制、撤回确认、删除再撤销；打开各操作菜单再取消 → 复制是pending；编辑completed组保留完成时间；撤销回原位置；取消不改数据。
- 确认组后看120秒休息，点±15秒、跳过/关闭，换另一位学员训练 → 每课独立；通知允许/拒绝都不阻止记组，点击通知回原课，文案不含学员或训练值。
- 输入时打开键盘，保存后切后台再回来；退出并重开App → 确认入口和休息条不被遮住，已保存组/顺序可恢复；若要求复核时长，取消不写，确认非负整数后才继续结束。休息计时跨进程不承诺保留。
- 若自然遇到加载/恢复/保存失败，点重试 → 重读或重做原保存，不提前报成功；保存失败时不能结束。此处不要求负责人手工制造数据库故障，已有自动证明见T018。

### 结束、总结与历史

- 新开空课后结束 → 明确放弃，不生成completed历史、不扣课；含completed和pending/draft时先返回继续，再选丢弃未完成组结束 → 不静默丢弃。
- 可用包选“扣1课时”或“不扣课”；无包、到期、耗尽也各走一次结束 → 只明确扣课才有一笔ledger；其他不自动扣、不中断记录；无有效包的私有标注可查。若训练已完成但扣课失败，两种结果分别说明，不误报扣课成功。
- 保存重点、学员可见总结和教练私密备注 → 保存后返回今日，历史能打开；退出未保存总结不代写。
- 历史切7/30/90天、重点/动作筛选再清除；打开详情、仅改重点、另存模板，均试取消 → 只列completed、快照不随库名变化，改重点不重扣；模板不复制学员/账本/私密备注。内容写入失败重试复用已建模板ID，不重复创建。

## 5. 已定决策：走查时留意

| 决策 | 一句话 |
|---|---|
| D01 | Android读取旧包失败会阻止保存、旧包变化会重新确认；这是与iOS不同但按决策保留的防静默替换保护，iOS同缺口仍是待办。 |

| D03 | 组间休息通知属于S1；Android API33+按需申请POST_NOTIFICATIONS，拒绝不影响记录，系统通知可能延迟。 |
| D04 | 两端S1都没有重开训练/返还课时的UI入口，只测试底层幂等；不要找不存在的按钮。 |
| S1-D12 | 已裁决照iOS：仅session-complete扣减可幂等返还，ad-hoc扣减不返还；以后如改须两端一起改。 |
| S1-D16 | 手工调整是专门表单中的显式保存，与iOS一致，不再弹二次确认；取消/返回零写入。 |
| S1-D18 | 非空分段只确认后移到未分段并保留动作/组，不提供连同动作删除或删除时选目标；独立移动入口仍有。 |
| S1-D20 | debug/release都默认进入S1，S0隐私测试壳不是日常入口。 |
