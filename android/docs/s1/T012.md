## 集成合同

- `ExerciseLibraryScreen(state, onBack)`：T016 可在 `S1Routes.EXERCISES` 接线；只通过 callback 返回。
- `TemplateListScreen(state, onNavigate, onBack)`：T016 可在 `S1Routes.TEMPLATES` 接线；创建/选择发出 `S1Routes.templateDetail(id)`。
- `TemplateEditorScreen(state, id, exercises, onBack)`：对应 `S1Routes.TEMPLATE_DETAIL`。
- `ExercisePicker(state, onSelect, onDismiss)`：独立 composable，不引用模板页面、路由或 TemplateUiState；T013a 可直接复用。`ExerciseSelection` 提供 name/mode/sourceKind/sourceID；仅本节返回 `sessionOnly/null` 的草稿。**消费方负责生成 SessionExerciseID、调用 `claimSessionOnly(StableExerciseID.parse(id.value), name)` 并持久化 Session snapshot**，成功返回 `ApplicationResult.Success(Unit)` 才关闭；失败保留输入。库内选择使用稳定 catalog ID 和当前显示名/模式 snapshot。
- “加入动作库”是显式且独立的 durable create；成功刷新匹配行，由教练点选加入当前 owner，不隐式把“仅本节”升级为全局动作。仅取消选择器不会创建 catalog 或 Session 行。
- `ApplyTemplateSheet(state, target: SessionRecord, onApplied, onDismiss)`：只在明确点击“应用”时调用 `ApplyTemplateSnapshotCommand`，携带打开时展示的 template/session revision；stale 不覆盖，不自动重试写入。回调只发生在真实事务成功后，取消不写入。
- TemplateUiState/ExerciseUiState 应由调用方 `remember` 或生命周期 owner 保持；注入现有 use case、repository、clock、ID generator。创建有 generation 校验的 repository 时须在后台初始化。重新开库后重建状态及依赖。

## 与 iOS 的对应与差异（增加与移除）

| 位置 | 当前 iOS | Android 目标/实际 | 保留、移除及理由 |
|---|---|---|---|
| 移入分段 | confirmationDialog | `FcBottomSheet` + `FcActionRow` | 按 AD-03 映射；未新增菜单类型，取消保留 |
| 动作/分段重排 | List.onMove / swipe | 可见行打开操作面板，上移/下移、移入分段 | 保留持久顺序及统一 order axis；用可发现按钮，不依赖长按 |
| 模板名称/训练重点 | 名称变化后即时保存 | “编辑模板”草稿 + 明确“保存” | 保留最终字段与 CAS，取消不写入；与 iOS 的提交时机有差异，待负责人统一走查 |
| 模板动作来源 | 编辑器快速按名称添加 | 共用可搜索动作选择器，支持 catalog snapshot / 本地名称 | 落实 T012/T013a 复用要求 |
| 计划组 | 模板保存计划值 | 明确添加/编辑/删除本地草稿，再“保存计划组” | 不生成 completed 状态；取消丢弃草稿，保留已存内容 |
| 快速加入库 | 显式保存到库 | 显式“加入动作库”，再点选结果行 | 不隐式全球化；存在两次点击的交互差异，待统一走查 |
| 分段删除 | 空分段直接删除；非空仅确认后移到未分段再删除分段 | 照搬 iOS；复用 DS-CONFIRM-DIALOG | 移除连同动作删除与删除流程目标选择；保留动作 ID、计划组及独立移动（AD-03） |
| 模板列表排序 | 无自由模板列表排序合同 | 保留 repository 的更新时间排序 | 没有 template-list order 字段/API，不伪造拖动顺序；本任务“模板移位”落实为模板内分段与动作顺序 |
| 动作库布局 | 部位/器械筛选、器械图标与最近练过 | 当前为搜索与普通 DS-LIST-ROW，未实现独立筛选/最近区/器械图标 | 这些 iOS 视觉与浏览差异仍需负责人确认；不声称像素或完整布局等价 |
| 其他里程碑入口 | 完成总结/历史可另存模板，训练中含组确认 | 不在本项挂入口 | FR-022 的入口归 T014/T015；Session 排序/完成组保护归 T013a，未修改冻结核心 |
