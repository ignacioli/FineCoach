## 行为与 iOS 对齐

- `normalizedName` 复用 `parseDomainName`（trim、NFC、UTF-8 64 KiB）；大小写没有被擅自折叠为 claim identity。claim 的 PK 是全局名称，activeCatalog/currentSession 是生命周期作用域，不是允许跨 scope 重名的 namespace。同 owner + 同 scope 可幂等取得；不同 owner 或不同 scope 冲突。
- `saveCustom` 在同事务取得新 claim、修改行、释放旧 claim、重算内置 claim；失败保留旧值。内置项不可通过自定义编辑路径修改；归档释放名称，恢复须重新取得名称；隐藏偏好不释放名称。
- `renameClaim(currentSession)` 不创建 catalog 行；显式 `createCustom` 才入库。不隐式把课内动作转全局。T008 可在自己的 Session 结束/删除事务内调用 `releaseSessionClaimsInTransaction`；该方法强制已有 Room transaction，并立即重算内置 claim。Session/模板写入与完整生命周期接线仍由 T008 实施。
- `synchronizeCatalog` 按 stable ID 原位更新、新增，保留 createdAt 与偏好，自定义 ID 撞车整笔回滚；消失的内置项标为 retired，仍可按 ID 取得。custom/currentSession 既有 claim 优先，同名内置项动态隐藏而不写 retired。归档、改名或释放课内 claim 后立即重算。
- `search` 仅返回可选择的 active、非 retired、非 hidden、未被优先 claim 遮挡的行；匹配名称、alias、部位、器械、全拼与首字母，大小写/音调不敏感。拼音 token 按名称内容缓存，改名后不复用旧内容；不进行网络访问。canonicalName 保持真实 catalog 名称，alias 通过 preference 读取用于显示，不把显示偏好写回名称或历史 snapshot。
- `listCatalog` 是完整身份读取，保留 archived/hidden/retired 行，供编辑恢复和历史引用；选择器必须用 search 的可选集合。`preference(id)` 与 loader metadata 分别保留辅助/单侧覆盖和内置单侧默认值，null 单侧覆盖不强制改为 false。
- 自定义改名/隐藏、内置目录升级改名/模式变化、retired 同步均不写 Session/Template 表；测试保存真实历史和模板 snapshot 并在重开后比较。

已知接口与平台差异：冻结的 Android `UpdateExercisePreferenceCommand` 是完整替换（null alias 清空、null isUnilateral 回到目录默认），iOS `setPreference` 是可选字段局部更新（null alias 不改、空白清空）。调用方应保留其他偏好后提交完整 command；本轮不改 port。Android 拼音由 ICU、iOS 由 Foundation 推导，多音字/分词的全部等价性未确认，常见全拼/首字母由宿主测试验证。Android 查询固定按 canonicalName/id 排序，不声称两平台全部 locale 排序一致。
