## sourceEventKey 一致性说明

- iOS `CreditLedger.swift:118-139` 使用 `uuidString`（大写 UUID 片段）。
- Android 在 `CreditLedgerSourceEventKeyFactory` 中保持 ID 存储为小写 canonical，同时在构造 key 文本时将 UUID 段转大写。
- 该规则是 FCBK 互通与幂等比对要求：`sourceEventKey` 需与 iOS 逐字节一致。
- 备注：`SourceEventKey.parse` 中 `raw.trim()` 属既有残留，本轮（amend2）按白名单不改该逻辑。
