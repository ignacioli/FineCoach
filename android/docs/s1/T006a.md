## 行为与边界

- 保存通过既有 Student Domain 做 NFC / Unicode trim、sex 必填和 64 KiB UTF-8 校验；可选字段空白转 null；允许同名不同 ID。save 按冻结 port 是 upsert，已有记录保留数据库中的 createdAt。用例 create/update 提供 draft 入口。
- 默认只列 active；`includeArchived=true` 包含两种状态（归档页可筛选 lifecycle）。姓名搜索使用规范化文本的 literal substring，忽略大小写和组合变音符；`%` / `_` 不作为 SQL wildcard。按 displayName、UUID 排序。
- archive/restore 在事务中读取当前状态，调用 Domain 的状态转换并使用注入 Clock，重复同方向转换拒绝；错误不变成成功。
- 所有阻塞 Room 操作在 `Dispatchers.IO` 执行；多步 mutation 用阻塞事务闭包，不在事务中切换 coroutine。事务完成之后才返回 Success。数据库异常转 `persistenceFailed`，不输出异常消息/业务日志，CancellationException 继续传播。
- 删除事务：重读 Student → 查询该 Student 的任意 inProgress Session（不依赖 pointer）→ Domain 校验确认姓名 → TrainingSet → SessionExercise → session_training_focus → Session → 指定 archive identity → Student。任何一步失败整笔回滚。
- archive identity 精确删除 `archive.studentID.<UUID>`，兼容 iOS 大写 UUID 与 Android canonical 小写 UUID；不使用 prefix/LIKE 删除，不影响其他学员或其他全局设置。
- 不删除 CoursePackage、CreditAdjustment、active package claim、SessionSection、active session pointer；不借完成/放弃 Session 的路径清理它们。不删除全局 catalog/preferences/name claims、模板/planned sets、store generation 或其他 metadata。
- **ShareReport 属 S4，当前没有表，没有清理实现或已清理声明。**

FR-001/002/003/005/006/008 的学员数据操作在本任务实现。FR-004 详情的课包/历史、FR-007 继续对应 Session 由冻结的课包、Session、History ports 和 T007～T010 接线；本任务不新增 UI、开课流程、展示错误状态或未批准入口。删除前的影响展示属于 T010 UI；本任务完成提交时的权威事务校验，不宣称 UI 已实现。archived 学员开课保护由既有 Domain `canStartSession` 与后续 T008 承接。
