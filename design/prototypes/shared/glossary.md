# 界面用词（低保真）

规格与技术交流可使用英文领域词；简体中文界面使用下表。不要在 UI 中直出 Appointment、Session、Student、Share Report 等英文领域词。

本表来自 `specs/CONTEXT.md` 与 `specs/ideas.md` 第 9.6 节，仅服务原型走查，不是批准 PRD。

| 领域概念 | 界面文案 |
| --- | --- |
| Student | 学员 |
| Student Contact Details | 电话 / 微信（选填，教练手输） |
| Appointment | 课程安排 |
| Next Appointment | 下一节课 |
| Session | 不直出；语境用「训练」 |
| Start Session | 开始训练 |
| Active Session | 训练中 |
| Resume Session | 继续训练 |
| End Session | 结束训练 |
| Session Summary | 训练总结 |
| Completed Session | 训练记录 |
| Session Section | 分区（热身 / 主训练 / 辅助 / 放松） |
| Training Focus | 训练重点 |
| Course Package | 课包 |
| Credit Adjustment | 课时调整 |
| Built-in Exercise | 内置动作 |
| Custom Exercise | 自定义动作 |
| Session-only Exercise | 仅本次动作 |
| Reusable Training Template | 训练模板 |
| Set | 组 |
| Personal Record | 个人最佳 |
| Private Coach Note | 教练备注（不进入分享） |
| Student-facing Summary | 学员课后总结 |
| Share Report | 分享报告 |
| Personal Training Archive | 个人训练档案 |
| Personal Training Archive Viewer Mode | 档案查看 |

避免在界面用「开始课程」「课程记录」指代实际发生的训练，以免与课程安排混淆。
