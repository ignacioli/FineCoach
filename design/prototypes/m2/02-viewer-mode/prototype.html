走查说明

低保真线框。本模块只覆盖：首次启动选择 → 导入个人训练档案 → 冲突拦截 / 同来源再导入 → 只读查看模式（浏览、搜索、筛选、显示设置、本机删除）。不是教练工作模式，也不是角色切换。
本模块不做
  • 添加训练、编辑来源数据、生成教练工作数据
  • 分享报告编写器、公开链接、远程撤回
  • 多来源档案、教练工作空间内的身份切换
  • 把档案混入已有教练数据（禁止合并）
建议路径
  1. 首次启动：导入个人训练档案
  2. 系统文件选择器 → 输入密码 → 进入查看首页
  3. 场景 C 看冲突拦截；场景 D 看同来源再导入
  4. 浏览课程 / 身体与趋势 · 仅显示设置
  5. 设置中删除本机导入档案
