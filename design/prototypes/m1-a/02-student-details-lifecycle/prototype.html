走查说明

低保真线框。灰盒 + 发丝线。本模块只覆盖学员详情与生命周期，从模块 01 学员列表进入。
本模块不做
  • 底栏、「今日」、课程安排、课包、模板、身体数据、通知
  • 训练记录器内部、训练记录编辑、设置内部页
  • 登录 / 云同步 / 通讯录权限 / 微信能力
建议路径
  1. 小周详情：开始训练 → 上次摘要 → 资料
  2. 编辑选填项；改名后历史用新名称，编号不变
  3. 展开伤病/注意事项（默认折叠）
  4. 点历史进入训练记录详情出口
  5. 归档 → 已归档详情 → 恢复
  6. 永久删除（需输入显示名称）与训练中拦截

    必查状态

    1. 信息顺序：开始训练 → 上次训练摘要 → 资料；无下一节课卡片
    2. 性别 = 图形 + 文字，选项含男 / 女 / 其他 / 不透露
    3. 目标为芯片 + 自由文本，不自动开出训练内容
    4. 电话 / 微信手输，虚线标明不读通讯录
    5. 伤病默认折叠，有最近更新时间，声明非医疗诊断
    6. 训练页只预览「有注意事项」出口，不绘制记录器
    7. 两位林林用教练备注区分；备注不进分享报告
    8. 改名后稳定编号不变，历史显示新名称
    9. 历史倒序 3 条，点开为训练记录详情出口
    10. 归档后不能新开训练，可看历史并恢复
    11. 训练中不可永久删除；否则需输入显示名称并建议先备份
