## 设计优化清单

1. 视觉方向重构：MD3 默认紫 + 全 400 字重 → 暖炭黑素雅（克制、安静、效率工具气质）
2. 色彩系统：炭黑主色 + 暖中性灰 + 双状态色 + 橙点缀，无饱和高亮抢戏
3. 对比度/可达性修复：次文字对比度、月历 CTA、分段胶囊、今日 hero 面板米色→炭黑、状态图标颜色统一
4. 空态屏：兔子吉祥物 + 温馨文案「还没有学员 / 开始记录第一堂课吧」+ 炭黑 CTA「＋ 新建学员」
5. 器材 icon 库：15 个统一描边 icon（杠铃/哑铃/单车/跑步机/跳绳/壶铃/划船机/徒手/弹力带/史密斯机/绳索/龙门架/哈克深蹲机/蝴蝶机/推肩机）
6. 训练页器材 icon：深蹲/卧推
7. 二选一按钮填充色：未选中项加米色 tint `#EDE9E2`，解决对比度过低
